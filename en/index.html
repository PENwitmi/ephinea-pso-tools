Ephinea Tools

Unofficial tools for PSO Blue Burst (Ephinea server). Answer "which character's bank was that item in?" and "what does this gear actually do?" right in your browser.

1️⃣ Import your character data (1 min, optional) → 2️⃣ Item List to search every character and bank at once → 3️⃣ Simulator to build with gear you actually own
No import needed to use the simulator — it ships with the full equipment database.

1️⃣ Import character data

Just drop the character data files e-mailed to you by Ephinea (.psochar / .psobank) — all of them at once, no converter needed. Every character's inventory, bank and the shared bank are loaded, plus character names, classes and levels. Everything is processed and stored only inside your browser; nothing is ever sent anywhere.

How to get your character data (official)
  1. Enter your account name and password on Ephinea's official Download Character Data page
  2. Your registered e-mail address receives the character data (.psochar / .psobank / .psoclassicbank files). Drop them all into the import box below

Note: you can also import an EPHINEA CHARACTER VIEWER-exported AllItems_with_slot.txt (English) as before

2️⃣ 📦 Item List

Solves "which character's bank was that rare in?" — search and filter every character's inventory, bank and the shared bank at once, with Price guide-based PD value estimates on the side.

3️⃣ ⚔️ Stat Simulator

Pick a class, level, mag, materials and gear to see your stats and every equipment effect at a glance — including which item each effect comes from, which attack-speed source wins, and what completes the Thirteen set effect. Import your data and owned items get a 🔖 badge so you can plan builds with gear you actually have.

🎯 Wishlist

Add the items you want and reverse-look-up which difficulty, Section ID and enemy (or box) drops them, at what rate. With PD value estimates. If you've imported your data, items you already own are marked as owned.

Data sources: Ephinea PSO Wiki (equipment, prices, technique mechanics) / character growth data follows vanilla PSOBB / Inspired by the classic status simulator

Imported inventory data is stored only in your browser (localStorage) and never sent to any server.
