Gear cards

-

  • "Base total" = base + mats + mag + units + effects (MST/LCK exceptions etc.), before the cap. Anything above the cap is shown in red and not applied. Green ✓ means exactly at the cap.
  • "Diff" = base total − cap; a guide for tuning your material and mag allocation.
  • "Final" = capped base total + gear (weapon ATP, armor DFP/EVP, set effects). Gear has no cap (wiki Stats: total stats have no limit).
  • How the cap counts (per Ephinea admin Matt): mags, units and materials count toward the cap; weapons, armor and shields do not. However, MST and LCK are exceptions — everything, gear included, is capped and can never exceed the limit (these exceptions appear in the Effects column). No item on Ephinea raises the caps themselves.
  • ATA shows one decimal (internally ×10 integers). Each mag DEX gives +0.5 ATA.
  • Variable frame/barrier/weapon stats are set with sliders (default = max roll).
  • Non-stacking effects like attack speed apply the highest source only; losing sources are struck through.
  • How effects stack: technique power adds up / TP cost reduction multiplies / attack speed & V50x: only the strongest applies / Megid pierce does not stack / range boost stacking is documented nowhere and unverified, so overlaps show a single boost (+100%) only.
