Ephinea Tools

PSO Blue Burst (Ephineaサーバー) の「どのキャラのどの倉庫に何があるか分からない問題」と「この装備、結局どんな効果?問題」を解決する非公式ツールです。

1️⃣ キャラクターデータを取り込む(1分・任意) → 2️⃣ アイテム一覧で全キャラ・全倉庫を横断検索 → 3️⃣ シミュレーターで「家にある装備」からビルドを組む
取込みなしでも、シミュレーターは全装備データ入りでそのまま使えます。

1️⃣ キャラクターデータ取込み

Ephinea公式からメールで届くキャラクターデータの中の AllItems_with_slot.txt を選ぶだけ。全キャラの所持品・個人倉庫・共有倉庫がまとめて読み込まれます。データはあなたのブラウザ内にのみ保存され、外部には一切送信されません。

まだデータを持っていない場合 — 入手方法 (Ephinea公式)
  1. Ephinea公式の Download Character Data ページでアカウント名とパスワードを入力
  2. 登録メールアドレスにキャラクターデータ(アーカイブ)が届く
  3. 解凍すると中に AllItems_with_slot.txt が入っています。それを下の取込み欄へ
Ephineaから届いた AllItems_with_slot.txt をここへ
クリックしてファイル選択 / ドラッグ&ドロップ どちらでも
テキスト貼り付けで取込み

2️⃣ 📦 アイテム一覧

「あのレア武器どのキャラの倉庫だっけ?」を解決。全キャラの所持品・個人倉庫・共有倉庫をまとめて検索・絞り込み。ついでに相場(Price guide準拠のPD評価)の目安も分かります。

3️⃣ ⚔️ ステータスシミュレーター

職業・レベル・マグ・マテリアル・装備を選ぶと、ステータスと装備効果が一目で分かります。「この効果はどの装備から出ているのか」「攻撃速度はどれが優先されるのか」「Thirteenのセット効果は何と組めば発動するのか」まで表示。データを取り込むと所持品に🔖が付き、持っている装備だけでビルドを検討できます。

データ出典: Ephinea PSO Wiki (装備・相場・テクニック仕様) / キャラクター成長データはバニラPSOBB準拠 / Inspired by 旧ステータスシミュレーター

入力されたインベントリデータはブラウザ内(localStorage)にのみ保存され、サーバーには一切送信されません。
