Ephinea Tools

PSO Blue Burst (Ephineaサーバー) 用の非公式ツール集です。「あのアイテムはどのキャラの倉庫だっけ?」「この装備はどんな効果?」をブラウザだけで解決できます。

1️⃣ キャラクターデータを取り込む(1分・任意) → 2️⃣ アイテム一覧で全キャラ・全倉庫を横断検索 → 3️⃣ シミュレーターで持っている装備からビルドを組む
取込みなしでも、シミュレーターは全装備データ入りでそのまま使えます。

1️⃣ キャラクターデータ取込み

Ephinea公式からメールで届くキャラクターデータ(.psochar / .psobank ファイル)をそのまま全部まとめてドロップするだけ。変換ツールは不要です。全キャラの所持品・個人倉庫・共有倉庫に加えてキャラクター名・職業・レベルも読み込まれます。データはあなたのブラウザ内でのみ処理・保存され、外部には一切送信されません。

キャラクターデータの入手方法 (Ephinea公式)
  1. Ephinea公式の Download Character Data ページでアカウント名とパスワードを入力
  2. 登録メールアドレスにキャラクターデータ(.psochar / .psobank / .psoclassicbank ファイル)が届く。それを全部まとめて下の取込み欄へ

補足: EPHINEA CHARACTER VIEWER で書き出した AllItems_with_slot.txt (英語表記) もこれまで通り取込めます

公式から届いた .psochar / .psobank ファイルをまとめてここへ
クリックしてファイル選択 (複数可) / ドラッグ&ドロップ どちらでも。AllItems_with_slot.txt も可
テキスト貼り付けで取込み

2️⃣ 📦 アイテム一覧

「あのレア武器どのキャラの倉庫だっけ?」を解決。全キャラの所持品・個人倉庫・共有倉庫をまとめて検索・絞り込み。ついでに相場(Price guide準拠のPD評価)の目安も分かります。

3️⃣ ⚔️ ステータスシミュレーター

職業・レベル・マグ・マテリアル・装備を選ぶと、ステータスと装備効果が一目で分かります。「この効果はどの装備から出ているのか」「攻撃速度はどれが優先されるのか」「Thirteenのセット効果は何と組めば発動するのか」まで表示。データを取り込むと所持品に🔖が付き、持っている装備だけでビルドを検討できます。

🎯 欲しいものリスト

欲しいアイテムを登録すると、どの難易度・どのSection IDで誰(どの箱)からどの確率でドロップするかを逆引きできます。PD相場の目安付き。データを取り込んでいれば、既に持っているものは所持済みとして表示されます。
