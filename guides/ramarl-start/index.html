アルティメット到達おめでとう

RAmarl / Section ID = Greenill 向けの、これから何を掘りに行くかの見取り図。 上から順に「まず狙う → その次 → 長期の目標 → 余裕があれば」と並んでいます。 急がなくていいし、順番も自由。

rate は敵1体あたりのドロップ確率。Hildetorr / Dorphon Eclair / Merissa AA はレア変異で、通常敵の 1/500 の確率でしか湧かないので、表示上の 1/2 は「レア変異が湧いた1体から出る確率」であって、実効的なドロップ確率は 1/1,000 相当になる。

各カードの右上に 自力 と 他色に依頼 のチップを付けた。Greenill / Pinkal / Redria の3色で妥当に掘れるものが自力、Bluefull・Oran・Yellowboze などのキャラに頼むしかないものが依頼。

まず狙う(アルティメット序盤を安全にする)

レア変異は湧きに左右されるので、まずは非レアで確実に回せるスプレッドニードルから。フローズンシューターは平行して Hildetorr が湧いたときに拾う。

スプレッドニードル Spread Needle 武器 / ライフル 自力
Greenill Ep1 Merlan 1/900 / Redria Ep1 Dark Bringer 1/358
効果
1発で5発同時発射するライフル。スペシャル攻撃は麻痺(Seize)、5体対象
メリット
群れる敵の相手が一気に楽になる。麻痺を撒ければ数体をまとめて止められる。フローズンシューター(単体凍結)と役割が違うので、両方あると場面ごとに使い分けられる
フローズンシューター Frozen Shooter 武器 / ライフル 自力
Greenill Ep1 Hildetorr 1/2 レア変異
効果
単体対象のライフル。スペシャル攻撃は100% 凍結(凍らない敵を除く)。凍った敵はダメージが増える
メリット
アルティメット序盤は敵の攻撃1発でHPが吹き飛ぶが、この1本があれば「凍らせて→殴る」の型で安全に処理できる。パーティでも動きを止めるだけで貢献になる。特に速い敵に効く
デメリット
装備したまま2分経つと、25% の確率で自分が凍る(wiki 明記の仕様)。長時間の道中でずっと持ち替えないと事故る。
通常攻撃の ATP は 240〜250 と控えめで、非スペシャル運用ではライフル上位に劣る。スペシャルの凍結でCC(妨害)する武器と割り切る。
ボスなど凍結が効かない相手には出番がない。持ち替え前提。

その次(命中と手数を底上げする)

V101 ユニット 他色に依頼
Oran Ep1 Sinow Blue 1/3,034 Viridia Ep1 Crimson Assassin 1/2,291 Yellowboze Ep1 Baranz 1/2,965 Greenill Ep4 Zu 1/2,048
効果
ATP / DFP / MST / EVP / LCK 各 +15、ATA +1.5、攻撃速度 +40%
メリット
本命は攻撃速度 +40%。1秒あたりの発射数が 1.4 倍になるので、火力が実質 1.4 倍になる。ステ +15 も乗るので、攻撃速度専用ユニット(Heavenly/Battle)の上位互換。RAmarl の装備の中では単独最強クラス
掘り方
Greenill でも Ep4 Zu から出るが、1体ごとに出会う機会が少なく実プレイでは狙いにくい。定番は Oran のシノワブルー(Lost SOUL BLADE / Knight of Coral の周回)。Greenill / Pinkal / Redria の3色だけでは狙いが立ちにくいので、Oran / Viridia / Yellowboze のキャラを持つ人にお願いするのが現実的
V501 ユニット 他色に依頼
Bluefull Ep2 Sinow Berill 1/1,024 Bluefull Ep2 Delsaber 1/1,024 Pinkal Ep2 Deldepth 1/1,280
効果
凍結・感電・麻痺・混乱・即死のスペシャル攻撃の成功率 +50%(テクの状態異常や、Devil's / Demon's のような HP 吸収系は対象外)
メリット
スプレッドニードル(麻痺)や後述のカノンルージュ / オフェリセーズ(混乱)のスペシャルが決まりやすくなる。フローズンシューターは既にスペシャル 100% 凍結なので V501 の恩恵は無い
掘り方
Greenill では出ない。Pinkal の Deldepth でも出るが、Bluefull の Ep2 海底で Sinow Berill / Delsaber を回した方が数が出るので現実的。Bluefull のキャラがある人に頼む

長期の目標

ヘブンストライカー Heaven Striker 武器 / ハンドガン 自力
Greenill Redria Ep4 Pyro Goran 1/3,344
効果
ハンドガンだが通常攻撃はライフル並みの射程・自動照準。スペシャル攻撃はBerserk(HP を消費して超高火力を撃つ)。単体対象
真価
Striker Unit(セルマグ)を装備している状態だと、スペシャル攻撃が Divine Punishment に変わり本領を発揮する(内部の「ビート時間」の百の位が偶数の間だけ切り替わる = 約半分の時間帯)。Striker Unit は Heaven Striker Coat(マグセル)を Lv50 以上の Garuda に使うことで作れる4段階進化のセルマグ
メリット
ボス戦の削り速度が別物になる。ドロップ率が低いので、日々のクエストの副産物として狙う。イベント時の Maximum Attack E で狙うと現実的
Limiter → Adept ユニット(Sealed) 自力
Pinkal Ep4 Girtablulu 1/394 (Greenill では出ない)
効果
Limiter 自体は装備するとステータスが下がる封印品(ATP / MST / EVP / DFP / LCK 各 -30、ATA -10、全属性耐性 -10)。 Limiter を装備した状態で敵を 20,000 体倒すと、インベントリの Limiter に 「Use」が出て、Adept というユニットに化ける。
Adept の効果: ATP / DFP / MST / EVP / LCK 各 +10、ATA +20、 EFR / EIC / ETH / EDK / ELT 各 +6、TP消費 -25%(重ね掛け可能)
メリット
V101 が攻撃速度で手数を稼ぐのに対し、Adept は ATA を +20 大幅に伸ばしつつ、全ステータス・全属性耐性を底上げし、TP 消費まで軽減する。命中が火力に直結する Ranger では効きが大きく、V101 とは別軸で不可欠なユニット
レッドリング Red Ring バリア 自力
Greenill Redria Ep1 Dark Falz 1/186
効果
ATP / ATA / MST / LCK 各 +20、DFP・EVP は大幅上昇、EFR / EIC / ETH 各 +30、EDK / ELT 各 +5、パッシブ HP / TP 回復。装備には Lv180 以上が必要
メリット
攻撃・命中・防御・耐性が同時に上がる万能バリアで、ほぼ全キャラで最強クラスのエンドコンテンツ級装備。装備には Lv180 が必要なので、Lv80 の今からは長い道のり。Dark Falz は Lv80 でも(パーティを組めば)倒せるので、拾うだけ拾って倉庫で待たせておく手もある
